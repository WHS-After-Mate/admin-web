# WHS After Mate Admin Web

WHS After Mate 서비스의 **관리자용 웹 데모 프로젝트**입니다.

실제 의료기관에서 운영 중인 관리자 시스템이 아니라,
WHS After Mate의 서비스 흐름과 앱 연동 구조를 시연하기 위해 제작한 **프로토타입 및 데모용 웹사이트**입니다.

## 배포 사이트

https://dist-two-sigma-dhm7xzd6o1.vercel.app/

## 주요 기능

* 관리자 로그인
* 대시보드

  * 전날 방문 고객
  * 금일 방문 고객
  * 익일 예약 고객
* 신규 고객 등록
* 고객 검색 및 관리
* 고객별 관리 내역 조회
* 시술 및 관리 정보 등록
* 이용권 및 관리 횟수 확인
* 예약 관리

## 프로젝트 목적

WHS After Mate는 시술 후 고객이 필요한 사후관리 정보를 보다 쉽게 확인할 수 있도록 지원하는 서비스입니다.

본 관리자 웹은 실제 클리닉에서 사용하는 기존 시스템을 대체하기 위한 서비스가 아니라,
**클리닉의 고객 및 시술 데이터가 WHS After Mate 앱과 연동되는 과정을 시연하기 위해 별도로 구현한 데모 관리자 페이지**입니다.

실제 서비스 적용 시에는 각 의료기관에서 사용 중인 CRM, EMR 또는 고객관리 시스템과의 연동을 고려합니다.

## Demo

본 프로젝트에 포함된 고객, 예약 및 관리 데이터는 서비스 시연을 위한 데이터이며 실제 고객 정보가 아닙니다.
